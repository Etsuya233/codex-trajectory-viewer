## 性能

首屏时间以浏览器导航为起点，记录表格提交后第二次 `requestAnimationFrame` 回调。每次采样确认 50 条摘要已渲染。冷开表示已监听的服务中首次请求该日志，复用 Edge 进程和操作系统缓存。已有索引表示在同一服务完成索引后重新加载网页。HTTP 使用 `no-store`。

两组已有索引样本均在 1 秒内显示首屏。索引就绪的页面指标包含下一次轮询和浏览器调度。地址中追加 `&measure=1`，可在轨迹表格读取 `data-first-rows-ms`、`data-indexed-rows-ms`、`data-render-committed-ms` 与 `data-summary-request-ms`。

独立使用 Node HTTP 客户端请求并解析已有索引的摘要。真实样本耗时 100 / 44 / 39 / 21 / 13 / 23 / 17 ms，中位数 23 ms，响应 36,576 B。大型合成样本耗时 35 / 30 / 21 / 16 / 15 / 15 / 16 ms，中位数 16 ms，响应 20,113 B。两种样本均返回 50 条摘要，API 样本与浏览器计时分别采集。

## 索引和数据语义

- 冷开从最多 8 MiB 的尾部读取临时预览，后台顺序建立索引。索引保存在进程内，最多缓存 8 个近期会话。索引重建时更换 generation，使旧的分页、增量和详情视图失效。去重依据为当前 generation 内的源字节偏移。
- 正常追加只解析新增字节，并读取一次大小最多为 256 B 的尾边界进行连续性校验。无变化时只查文件状态。读入的半行保留到补齐再解析。截断、文件身份变化、同长度修改或边界不符会重建单个会话。保留文件身份、长度及末端校验内容的外部原位编辑只能从状态或详情校验中发现。
- 历史分页与轮询在同一页面队列中串行处理。已到最新位置时自动跟随，浏览历史时保留视口锚点。表格使用固定高度虚拟列表。大量历史已加载时，时间线聚焦当前滚动位置附近 600 条事件。
- 工具输出按 `call_id` 关联，即使调用和结果跨页。后台命令使用明确的执行会话 ID、调用 ID 或执行项记录。完成状态来自显式退出码；缺乏可靠关联时显示独立命令记录及其输出。产出的思考摘要和工具内容按纯文本展示。
- 子代理入口从父日志的派发结果、V2 `SubAgentActivity` 或等待项生成。父索引在子文件不存在时仍能提供链接。测试单独打开并追加子文件后，父索引的 generation、revision 和累计读取字节均保持。可定位的子代理在点击时独立读取。
- 已加载摘要搜索只检查当前窗口里的简短内容。全会话搜索使用索引定位候选，按需读取当前会话的可搜索正文和相关结果，每页最多 50 条。正文详情按需返回，单次最多 32,768 UTF-16 代码单元。大于 64 MiB 的单条日志以带说明的占位记录展示。
- 压缩记录标记边界。显式外来线程、复制继承的 ordinal 前缀与文档化子代理继承边界用于标记继承数据。引用型 `history_base` 显示来源及边界，视图和统计覆盖本地选定文件。统计优先使用已去重的逐响应 Token 数据，普通历史日志可回退最新累计快照。有继承且缺乏可确认本会话的统计来源时显示未知，耗时只累计有记录的本会话已结束轮次。
- 会话发现只遍历活动和归档目录的文件名称。当前会话选择按 rollout 文件名定位，引用到其他 rollout 的历史段只标记边界，可按其独立会话 ID 打开。
